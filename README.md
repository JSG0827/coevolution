# 공진화 정착 연구소

고등학교 2학년 지구시스템과학 수업에서 개인별로 진행하는 기후이동·공진화 의사결정 시뮬레이션입니다. 서버나 회원가입 없이 브라우저에서만 실행됩니다.

## 50분 수업 운영 예시

- 0~5분: 교사가 활동 목표와 공진화 판별 기준 안내
- 5~13분: 1단계—배정된 지구환경의 관측 자료 해석
- 13~25분: 2단계—초기 정책 3개를 묶어 정착 전략과 근거 한 문장 작성
- 25~34분: 3단계—2055년 사건을 확인하고 대응 정책·예상 결과 선택
- 34~43분: 4단계—추가 대응 유무에 따른 주민·지구시스템 결과 비교
- 43~50분: 5단계—자료 기반 공진화 고리 완성 및 개인 결과지 PDF 제출

학생이 입력한 출석번호·별칭은 서버로 전송되지 않습니다. 같은 별칭에는 같은 주민 구성과 돌발 상황이 배정되므로 결과를 다시 확인할 수 있습니다.

## 교육적 설계

- 학생별로 연안 삼각주, 건조 농업분지, 고산 유역, 산림도시권 중 하나가 배정됩니다.
- 입력한 번호는 환경·주민 조건·보기 순서와 결과의 작은 변동 배정에 사용되며, 같은 번호에는 같은 조건이 다시 나타납니다. 입력값은 서버로 전송되지 않습니다.
- 13개 정책의 환경별 효과와 부작용을 반영해 각 환경의 4개 사건 후보 중 잔여 위험이 가장 큰 사건이 10년 후 발생합니다.
- ‘정책을 좋아하는 사람이 더 많이 온다’가 아니라, 이동이 필요한 1,200명이 **안정 정착·위험 노출·2차 이동·정착 대기** 중 어떤 상태가 되는지 계산합니다.
- 주민의 차이는 성격이 아니라 현재의 생계·건강·돌봄 조건에서 생긴 우선 필요로 표현합니다.
- 단일 총점이나 순위를 제공하지 않고 안전, 생계, 생태, 형평성, 저탄소 전환을 따로 보여줍니다.
- 정책 선택 전에 1,200명의 주민 구성과 집단별 주요 필요를 공개하고, 개인·가구별 선택과 적응에는 불확실성이 있음을 함께 알립니다.
- 초기 정책은 예산 계산 대신 동일 규모의 정책 묶음 3개로 단순화하며, 2055년 사건 대응에는 추가 자원 1개를 사용합니다.
- 결과 화면은 주민 결과·주민 필요 변화·지구시스템 변화를 서로 다른 영역으로 나누어 보여 주고, 9개 상세 지표는 펼쳐서 비교합니다.
- 환경 문항의 보기는 실제로 혼동할 수 있는 인과 경로로 구성되며, 학생별 순서는 달라도 같은 별칭에는 동일하게 유지됩니다.
- 마지막에는 인간의 선택이 지구시스템을 바꾸고 그 변화가 다시 인간과 생물에게 돌아오는 고리를 자료 선택으로 완성하고, 예상·실제 결과와 한계를 한 문단으로 해석합니다.
- 마지막 고리는 지구시스템 변화와 생물권의 능동적 반응을 별도 단계로 구분하며, 선택 방향이 어긋나면 정답을 강제하지 않고 설명이 필요한 연결을 알려 줍니다.
- 각 환경의 핵심 지구과학 용어 두 개에는 눌러 보는 짧은 도움말을 제공합니다.
- 각 단계의 ‘이전 단계’ 버튼으로 앞선 자료와 결정을 다시 볼 수 있습니다. 초기 정책을 수정하면 사건 이후 결과는 다시 계산되고, 단순히 결과를 다시 볼 때는 작성 내용이 유지됩니다.
- 여기서 공진화는 유전적 진화를 계산하는 뜻이 아니라 인간·생물권·지구시스템이 주고받는 사회–생태계 되먹임을 뜻합니다.
- ‘기후 난민’은 국제법상 공식적으로 인정되는 용어가 아니며, 이 활동은 기후와 생계·건강·정책이 함께 작용하는 기후이동을 다룹니다.
- 결과 수치는 실제 지역의 예측값이 아니라 변화 방향과 선택 사이의 상충 관계를 토론하기 위한 수업용 모형입니다.

## 로컬 실행

Node.js 18 이상에서 다음 명령을 실행하고 `http://127.0.0.1:4173`을 엽니다.

```bash
npm run dev
```

배포 전 확인:

```bash
npm run build
```

## GitHub에서 Vercel로 배포

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Vercel에서 **Add New → Project**를 눌러 저장소를 가져옵니다.
3. 이 폴더가 저장소의 하위 폴더라면 Root Directory를 `coevolution-migration-lab`으로 지정합니다.
4. Framework Preset은 `Other`, Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. `vercel.json`을 읽으면 자동으로 채워질 수 있습니다.
5. Deploy를 누릅니다. 이후 GitHub의 기본 브랜치에 푸시할 때마다 자동 배포됩니다.

정적 HTML·CSS·JavaScript만 전송하므로 별도 데이터베이스나 API가 필요하지 않습니다.

## 내용 수정 위치

- 환경, 정책, 주민 유형, 10년 후 사건, 계산식: `dist/simulation-v2.js`
- 화면 문구와 활동 단계: `dist/index.html`
- 색상과 화면 배치: `dist/styles.css`

개인 결과는 브라우저의 **PDF로 저장·인쇄**, **JPG 저장·공유**, **내용 복사** 기능으로 제출할 수 있습니다. JPG 버튼은 PC에서 이미지 파일을 내려받고, 지원되는 휴대폰에서는 공유 창을 열어 사진 앱·Drive·Google Classroom 등으로 전달할 수 있습니다.

## 교사용 학급 환경 고정

시작 화면의 **교사용 · 학급 환경 고정**을 펼쳐 환경을 선택한 뒤 **학급 링크 복사**를 누릅니다. 이 링크를 학생에게 공유하면 출석번호가 달라도 모두 같은 지구환경을 받습니다. 주민 구성과 결과의 작은 변동은 학생별로 유지되어 같은 환경 안에서도 서로 다른 정책 결과를 비교할 수 있습니다.
